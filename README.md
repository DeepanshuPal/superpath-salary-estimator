# Superpath Salary Estimator

An interactive salary estimator for content and marketing roles.

The form models compensation across experience, industry, job title, location, company stage, gender, and ethnicity, then produces a personalized estimate and report.

Live app: https://v0-build-my-website-chi.vercel.app/

## Run locally

Requires Node.js 18 or newer.

```bash
git clone https://github.com/DeepanshuPal/superpath-salary-estimator.git
cd superpath-salary-estimator
npm install
npm run dev
```

## Stack

Next.js, React, TypeScript, Tailwind CSS, and shadcn/ui.
